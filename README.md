## 📌 Descripción del Proyecto

Este proyecto es un **portafolio web personal e interactivo** diseñado para comunicar de manera clara la trayectoria académica, experiencia profesional y habilidades técnicas en el área de Desarrollo Full Stack e Ingeniería de Software.

El sitio ha sido construido aplicando estrictamente los estándares modernos de desarrollo web, priorizando:
- Una estructura en **HTML5 Semántico**.
- Una arquitectura visual mantenible y responsiva basada en **CSS Custom Properties** (Design System).
- Funcionalidad dinámica del lado del cliente mediante **JavaScript Vanilla**.

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Utilización de etiquetas semánticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<footer>`) para mejorar la accesibilidad y el SEO.
- **CSS3:**
  - Sistema de diseño propio (sin frameworks externos).
  - Variables nativas (`:root`) para la gestión centralizada de la paleta de colores, tipografía y espaciados.
  - Diseño responsivo utilizando **Flexbox** y **CSS Grid** adaptado a dispositivos móviles, tablets y escritorio.
- **JavaScript (Vanilla):** 
  - DOM manipulation para interactividad.
  - Persistencia de datos en navegador.

## ⚙️ Funcionalidades Interactivas (JavaScript)

El proyecto incorpora características interactivas para mejorar la experiencia del usuario, cumpliendo con los requerimientos técnicos:

1. **Menú de navegación *Responsive*:** Botón de hamburguesa (`☰`) que despliega los enlaces de navegación en dispositivos móviles.
2. **Cambio de Tema (Dark/Light Mode):** Botón alternador que modifica dinámicamente las variables de color CSS.
3. **Persistencia de Preferencias (`localStorage`):** El tema visual elegido (Claro/Oscuro) se guarda en la memoria del navegador y se mantiene al recargar la página.
4. **Filtro Dinámico de Proyectos:** Botones que permiten clasificar las *cards* de proyectos según su categoría (Inteligencia Artificial, Desarrollo Web, Todos).
5. **Auto-ajuste de Textarea:** El campo de "Mensaje" en el formulario de contacto recalcula automáticamente su altura en función del texto ingresado por el usuario, mejorando la estética y usabilidad.
6. **Botón Volver al Inicio (Scroll Top):** Botón flotante animado que aparece al desplazar la página hacia abajo y retorna fluidamente al encabezado al hacer clic.

## 🎨 Sistema de Diseño (Design System)

El proyecto incluye una sección dedicada a la documentación del **Design System**, la cual expone:
- Paleta de colores principal (Muted Gold, Warm Beige, Soft Black, Light Gray).
- Ejemplos de escala tipográfica (H1, H2, H3, Párrafos).
- Componentes modulares y reutilizables en todo el sitio, como botones, *badges* (etiquetas tecnológicas), inputs de formulario y *Cards* de proyectos.
